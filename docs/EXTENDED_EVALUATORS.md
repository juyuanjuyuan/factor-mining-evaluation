# 扩展评价模块

以下模块已经注册，但没有加入 `DEFAULT_EVALUATION_METHODS`。后续构建正式评价顺序时，
可以通过函数列表或 `--methods` 显式组合。

所有涉及收益的模块统一使用主流程标签：
`open[t+1+horizon] / open[t+1] - 1`。默认 `horizon=1` 时为
`open[t+2] / open[t+1] - 1`。

## 周期背景

方法名：`cycle_context`，依赖 `quantile_plot`，不加入默认 pipeline。

该方法不改变因子、收益标签或任何回测计算，也不写入新的 metrics、details 或
artifact 键。它只将现有的分位组累计收益 PNG 原地重绘为带背景色的版本；Web 运行详情页
会把同一背景用于 IC、累计收益和分段风险等折线图。

市场段落以中证全指（000985）的 25% 反转阈值划分：上涨段为红色、下跌段为绿色。已确认的
边界为 2013-06-25、2015-06-12、2016-01-28、2017-11-13、2018-10-18、2021-12-13 和
2024-02-05；2024-02-05 之后的上升段尚未由后续 25% 反转确认结束，因此在图表中标为“暂定”。
这些区间是事后市场语境，不能作为实时牛熊判断、因子筛选指标或未来收益信息。

## IC 持有期衰减

方法名：`ic_horizon_decay`，直接读取当前工作因子和开盘价 `o`，不依赖单一期限的
`rank_ic`。

模块使用与全项目一致的 next-open 口径：因子在交易日 `t` 收盘后形成，`t+1` 开盘进入，
持有 `H` 个交易日后的收益为：

```text
open[t+1+H] / open[t+1] - 1
```

横轴为 `H=20,21,...,252`。先根据最大持有期 `H=252` 确定结构上可计算的信号日期，
再保留能在全部 233 个期限上形成有限横截面 Rank IC 的共同日期集合 `T`。每个期限的
Mean Rank IC 都只在这组完全相同的 `T` 上求平均，因此不会因为较短期限拥有更多近期日期
而改变样本构成。明细写入 `details/ic_horizon_decay`，索引为持有期 `H`，唯一数值列为
`mean_rank_ic`。

不同持有期的累计未来收益大量重叠，曲线点并非独立样本；当前模块只展示预测能力随
持有期的变化，不定义或计算因子半衰期。

## 60 日滚动 Mean IC（50 日重叠）

方法名：`ic_peak_decay`，依赖 `rank_ic`。

当前模块只读取有效日度 IC，按时间顺序使用 60 个有效观测组成窗口，每次前移 10 个有效观测，
因此相邻窗口重叠 50 个观测，计算窗口平均值：

```text
mean_ic_k = mean(IC_(10k+1), ..., IC_(10k+60))
```

尾部不足 60 个观测的数据不纳入；明细索引使用每个窗口的结束日期，写入
`details/ic_peak_decay`，Web 端以折线图展示。半衰期的定义与计算暂不包含在当前模块中。

## 未来数据扰动

方法名：`future_data_perturbation`

默认从存在有效因子值的日期中等距选择 8 个 `t0`。对每个 `t0`：

1. 保留所有 `t <= t0` 的输入不变；
2. 对每个输入矩阵 `t > t0` 的有限值进行确定性随机扰动；
3. 重新计算因子并比较 `factor[t0]`。

采用 `rtol=1e-10`、`atol=1e-12` 比较。任何 checkpoint 发生变化都判定为失败。
该方法可以发现前视依赖，但随机扰动测试通过不构成数学上的绝对证明。

## Newey-West Rank IC 均值检验

方法名：`newey_west_ic_significance`，依赖 `rank_ic`。

自协方差定义为：

```text
gamma_k = (1/T) * sum((IC_t - mean(IC)) * (IC_(t-k) - mean(IC)))
```

将自协方差标准化为自相关系数：

```text
rho_k = gamma_k / gamma_0
```

从 `k=1` 开始，将 `abs(rho_k) <= 2/sqrt(T)` 视为落入白噪声近似显著性带。
当连续 3 个 `rho_k` 落入显著性带时，取该连续区间前一阶作为数据驱动带宽。
为覆盖 `horizon=H` 的重叠收益标签造成的机械相关，最终带宽强制满足
`L >= H-1`。`k=0` 不参与连续计数，因为 `rho_0=1`。

HAC 长期方差使用 Bartlett 权重：

```text
gamma_0 + 2 * sum((1 - k/(L+1)) * gamma_k, k=1..L)
```

输出均值、标准误、t 统计量、双侧渐近正态 p 值及 5% 显著性判断。

## IC 趋势滤波

方法名：`ic_trend_filter`，依赖 `rank_ic`。

该方法在同一张明细图中比较三种 IC 趋势处理：

- `filtered_ic`：一维局部水平卡尔曼滤波，固定 `Q/R=0.01`，稳态更新权重约为 9.5%；
- `second_order_low_pass_ic`：严格按周期参数 31 的二阶低通递推式计算，前三个状态取
  对应的前三个有效 IC；
- `fourier_low_pass_ic`：对完整有效 IC 序列做实数 FFT，仅保留周期不短于 31 个有效
  观测的频率成分，再逆变换回时间域。

卡尔曼和二阶低通是因果滤波；傅里叶低频重构使用完整样本，历史点会受到后续 IC 的影响，
因此只能用于事后诊断，不能直接作为实时交易信号。三种方法都不改变因子、收益标签或回测
收益，也不计算半衰期。缺失 IC 会先被剔除，`31` 指有效 IC 观测数而非严格的日历天数。

模块还输出 `ic_trend_filter_mean_10` 明细：分别在三条滤波曲线上计算 10 个有效观测的
窗口均值，窗口步长为 5，因此首个窗口是 `[t1, ..., t10]`，第二个是
`[t6, ..., t15]`，相邻窗口重叠 5 个观测。尾部不足 10 个观测时不输出，横轴使用窗口
结束日期。卡尔曼和二阶低通的窗口均值保持因果；傅里叶窗口均值仍继承全样本回看属性。

## 最高组表现

方法名：`top_quantile_performance`，依赖 `quantile_returns`。

- 默认十组时，最高组为 Q10；
- 其余组为 Q1-Q9；
- 日度跑赢要求 Q10 当日收益不低于 Q1-Q9 的每一组；
- 60 日窗口采用非重叠窗口，比较 Q10 窗口累计收益是否不低于 Q1-Q9 中的最高累计收益。

输出日度最高组收益、最高组累计收益、最高组年化收益、其余组平均收益、相对最佳其余组超额收益和
60 日窗口排名。`top_group_final_cumulative` 为仅做多最高组的期末复利累计收益：

```text
prod(1 + top_group_return_t) - 1
```

`top_group_annualized_return` 将该全样本复利收益按明细中的 `T` 个交易日、每年
252 个交易日做几何年化：

```text
(1 + top_group_final_cumulative) ** (252 / T) - 1
```

最高组日收益缺失时与累计收益口径一致，按 0 计入复利。

## Rolling Sharpe

方法名：`rolling_sharpe`，依赖 `quantile_returns`。

将 Q1-QN 的日收益按 20、60、252 个交易日切成完整的非重叠窗口，
分别计算每个窗口的年化 Sharpe：

```text
sqrt(252) * rolling_mean(return) / rolling_std(return, ddof=1)
```

无风险收益率按 0 处理。窗口按 `[t1...tW]`、`[t(W+1)...t(2W)]` 依次分段，
尾部不足 `W` 日的数据不参与统计；detail 每个完整窗口仅在结束日保留一行。
因此，60 日图中横坐标为结束日 `t` 的点，使用的是含 `t` 在内的 60 个有效交易日
`[t-59,\ldots,t]`；不是从 `t` 向后取数，也不是按日历日回溯。

metrics 输出对 QN 各窗口滚动 Sharpe 序列的分布摘要而非末值
（单个窗口末值只是一次实现，几乎没有筛选信息量）：

- `*_pos_share`：滚动 Sharpe 为正的窗口占比；
- `*_min`：最差窗口；
- `*_median`：中位数。

非重叠窗口序列写入 `details/rolling_sharpe_<window>`。同时将 60 日窗口的
所有分位组年化 Sharpe 画成折线图，写入
`plots/<factor>__rolling_sharpe_60.png`（重复执行时带版本后缀）。

## Rolling Drawdown

方法名：`rolling_drawdown`，依赖 `quantile_returns`。

将 Q1-QN 的日收益按 20、60、252 个交易日切成完整的非重叠窗口，
分别计算窗口内的最大回撤。每个窗口从初始净值 1 开始复利，返回窗口内最小的
`wealth / running_peak - 1`；尾部不足窗口的数据不参与统计。

metrics 输出分布摘要：`*_worst`（最深窗口回撤）与 `*_median`（中位数）。
非重叠窗口序列写入 `details/rolling_drawdown_<window>`。

## 入场可交易性过滤（开盘涨跌停/ST 剔除）

方法名：`tradability_filter`，额外需要 `o`、`limit`、`st` 数据。

评价标签在 `open[t+1]` 入场。若 `t+1` 日开盘触及涨跌停边界，涨停买不进、
跌停卖不出；若 `t+1` 为 ST/*ST，则按策略约束不交易。该方法用
`open[t+1] / close[t] - 1` 与逐股票 `limit` 矩阵比较，阈值为
`abs(gap) >= limit - 0.002`，并将触线或 ST 的标的在因子第 `t` 行置为
`NaN`，之后的分组、IC 等方法只看到可入场的样本。

- 与 `market_cap_neutralize` 一样，该方法替换工作因子，影响其后所有方法；
  应放在 `quantile_returns` 之前。若希望 IC 保持全市场口径，将其放在
  `rank_ic` 之后。
- 诊断输出分别统计开盘涨停、开盘跌停和 ST 剔除数量；这些分类可能重叠，合计
  不要求等于去重后的总剔除数。
- 局限：涨跌停判断使用复权价格和代码板块推导的 `limit` 矩阵，是代理口径；
  若后续接入交易所精确涨跌停价，应以 `limit_up/down` 价格替代该代理。出场日
  （`open[t+1+horizon]`）的流动性未建模。停牌无需处理——数据契约保持 `NaN`，
  其前向收益本身就是 `NaN`。

metrics 输出剔除样本总数、占有效因子值比例、发生剔除的天数及方向计数；
details 输出逐日剔除数量与占比。

## 市值中性化

方法名：`market_cap_neutralize`，额外需要 `cap` 数据。

每日截面执行：

```text
factor_i = intercept + beta * log(total_market_cap_i) + residual_i
```

使用最小二乘法，将残差作为后续评价方法使用的工作因子。输出每日样本数、截距、
市值系数、R² 和残差标准差。该方法只有被显式选择时才会加载市值矩阵。

## 行业中性化

方法名：`industry_neutralize`，额外需要 `industry` 数据。它不是默认 pipeline 的一部分。

每天按因子暴露日 `t` 的一级行业代码分组，在因子有限且分类存在的股票上执行：

```text
residual_i = factor_i - mean(factor_j for j in same_industry(i, t))
```

这等价于每天对因子执行“截距 + 行业固定效应”回归后取残差。行业内少于 3 只有效股票时，
整组置为 `NaN`，不会制造单股票或双股票的伪中性化结果。模块只使用同日分类，不向前或向后
填补行业标签；残差替换工作因子，之后的 IC、分组收益和回测方法自动使用该残差。

明细 `industry_neutralization` 逐日输出有效因子数、已分类数、使用数、未分类数、小行业剔除数、
行业数、合格行业数、行业解释 R² 和残差标准差；metrics 汇总中性化天数、平均 R²、覆盖率和两类
剔除数量。若先后串联市值和行业中性化，结果依赖顺序；同时控制两者应使用下述联合回归。

## 行业与市值联合中性化

方法名：`industry_market_cap_neutralize`，额外需要 `industry` 和 `cap` 数据。它不是默认
pipeline 的一部分。

每天在因子有限、行业分类存在、市值为正，且所属行业至少有 3 个此类股票的样本上，一次性拟合：

```text
factor_i = intercept + beta * log(total_market_cap_i)
           + sum(industry_fixed_effect_g * industry_dummy_i,g) + residual_i
```

实现使用“截距 + G−1 个行业 dummy”的基准行业编码；更换基准行业不会改变拟合值或残差。残差替换
当前工作因子，因此后续 IC、分组收益和回测方法自动使用同时剔除行业和总市值暴露后的因子。它与
`market_cap_neutralize` 后再接 `industry_neutralize` 不同：后者的结果依赖顺序，且第二次变换可重新
引入第一次控制的暴露。

明细 `industry_market_cap_neutralization` 逐日输出样本覆盖、行业数量、模型参数数、秩、残差自由度、
截距、可识别时的对数市值系数、联合 R² 和残差标准差；metrics 汇总中性化天数、平均联合 R²、覆盖率
及未分类、无效市值和小行业剔除数。若对数市值完全可由行业固定效应解释，对数市值系数会标为缺失，
但联合投影的残差仍然有效。
